# Security Notes

- Installer- und Uninstall-Befehle werden geloggt.
- Produktivaktionen erfolgen nur mit Benutzerbestaetigung.
- Registry-basierte Treffer werden nicht automatisch deinstalliert.
- Interne Installerpfade muessen aus vertrauenswuerdigen Quellen stammen.
- Konfigurationsaenderungen erstellen Backups von `config.json`.

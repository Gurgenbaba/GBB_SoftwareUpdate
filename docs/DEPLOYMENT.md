# Deployment

- Zielsystem: Windows 10/11.
- Verteile `dist/GBB_SoftwareUpdater.exe`.
- Runtime-Dateien werden unter `%LOCALAPPDATA%\GBB_SoftwareUpdater\` erstellt.
- Konfiguration zuerst via `%LOCALAPPDATA%\GBB_SoftwareUpdater\config.json` oder im Settings-Dialog setzen.
- Logs liegen unter `%LOCALAPPDATA%\GBB_SoftwareUpdater\logs\`.

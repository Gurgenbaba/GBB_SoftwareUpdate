# Deployment

- Zielsystem: Windows 10/11.
- Verteile `dist/Compexx-InstallTool.exe`.
- Runtime-Dateien werden unter `%LOCALAPPDATA%\Compexx-InstallTool\` erstellt.
- Konfiguration zuerst via `%LOCALAPPDATA%\Compexx-InstallTool\config.json` oder im Settings-Dialog setzen.
- Logs liegen unter `%LOCALAPPDATA%\Compexx-InstallTool\logs\`.
